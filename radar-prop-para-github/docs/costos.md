# Costos

**Hoy: $0 por mes.** Todo está en planes gratis (ver `docs/deploy.md`).

| Servicio | Límite gratis | Uso actual | Qué pasa si crece |
|---|---|---|---|
| Supabase | 500 MB de base, 5 GB de tráfico | ~70 MB | Con el ritmo actual (unas 30 propiedades nuevas por día) entra por años. Si se llena: plan Pro USD 25/mes. |
| GitHub Actions | Ilimitado en repositorios públicos | ~100 corridas por día de 3–4 minutos | Sin cambios. Si el repositorio pasara a privado: 2.000 minutos/mes gratis, no alcanzan para cada 15 min. |
| Render | 750 horas/mes, 512 MB de memoria | 1 servicio (cubre las 24 h) | Con más de ~15 personas usando a la vez conviene el plan Starter (USD 7/mes): no se duerme y tiene más memoria. |
| Netlify | 100 GB de tráfico/mes | Muy bajo | Sin cambios para un equipo de inmobiliaria. |

Lo único que se paga por uso, y solo si se activa, es el análisis con IA (Claude Haiku, unos USD 0,001 por aviso). Hoy está apagado.
